# Fashion MVP UX Wireframes

## Product Positioning

- AI fashion image generation from real product photos
- model styling mockups for marketing
- campaign, lookbook, and catalog visual generation

Do not position the MVP as fit-accurate virtual try-on.

## Primary Users

- Fashion designers
- Fashion buyers

## Screen 1: Upload

Purpose:

- ingest one or more product reference photos

Fields:

- product photos upload
- image type tags: front, back, detail, fabric, inspiration
- item name
- category

Rules:

- require at least one product image
- recommend front plus detail for best results

## Screen 2: Mode Select

Modes:

- `Model Styling`
- `Campaign`
- `Product Detail`
- `Variant Preview`

Default:

- `Model Styling`

## Screen 3: Style Setup

Preset-first controls:

- style preset
- background
- framing
- visual tone

Recommended style presets:

- Minimal luxury
- Contemporary streetwear
- Resort
- Editorial high fashion
- Clean ecommerce
- Department-store catalog

Recommended backgrounds:

- White studio
- Soft neutral studio
- Runway
- City street
- Luxury interior
- Resort exterior

Framing:

- Full body
- Three-quarter
- Waist-up
- Detail close-up

Visual tone:

- Commercial
- Balanced
- Editorial

## Screen 4: Model Setup

Controls:

- presentation: womenswear, menswear, unisex
- age band: young adult, adult, mature
- body type: slim, regular, curve, athletic
- look direction: neutral, luxury, street, avant-garde

Keep this lightweight. These are styling hints, not identity guarantees.

## Screen 5: Generate Board

Output:

- 4 candidate images

Board actions:

- Save
- Regenerate
- Make similar
- Upscale best
- Create 3 more from selected

## Screen 6: Refine

Quick chips:

- Keep garment closer to original
- More realistic fabric
- Cleaner commercial look
- More luxurious lighting
- Stronger editorial styling
- Simpler background
- More natural model pose
- Show product details better

Optional:

- one short free-text note

## Screen 7: Export

Actions:

- Download selected
- Export mini set
- Label as campaign, buyer deck, or PDP draft

## MVP User Flows

Designer flow:

1. Upload garment photos.
2. Choose `Campaign` or `Model Styling`.
3. Pick style preset and mood.
4. Generate the first board.
5. Refine toward the brand feel.
6. Export shortlisted visuals.

Buyer flow:

1. Upload product photos.
2. Choose `Product Detail` or `Model Styling`.
3. Pick a commercial preset.
4. Generate the first board.
5. Refine for clarity and realism.
6. Export the best one or two outputs.
